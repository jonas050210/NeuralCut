AI Editing Agent

Checking model route…

The agent turns instructions into a reviewable plan of validated tool calls. Read-only questions answer immediately; edits, imports, analysis, and exports wait for your approval. It can never run code or shell commands, and every applied edit is undoable. Without a configured local model, a deterministic built-in planner handles a bounded set of commands (try: “split clip <name> at 1s”, “add glow to clip <name>”, “how long is my timeline?”).
